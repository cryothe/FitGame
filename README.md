# FitGame

Log reps for five exercises and climb ranks: **Bronze → Silver → Gold → Diamond → Champion**.

## Exercises

Pushups, situps, leg raises, bicep curls, pullups.

## Rank cutoffs (lifetime reps)

| Rank     | Min reps |
|----------|----------|
| Bronze   | 0        |
| Silver   | 250      |
| Gold     | 1,000    |
| Diamond  | 5,000    |
| Champion | 15,000   |

## Run

```bash
npm install
npm run dev
```

Counts are stored in `localStorage` on this device.
